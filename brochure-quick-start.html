Quick Start — 15 Minutes

Your first AI response grounded in AA engineering standards — in 15 minutes.

The Hangar AI Constitution governs how AI assists software engineering at American Airlines — laws, skills, and workflows active in every session.

Get Started in 3 Steps
1
Clone the Constitution

Run this from your terminal. Replace YOUR_WORKSPACE with your working folder (e.g. ~/Repos).

git clone https://github.com/AAInternal/hangar-ai-constitution.git \ YOUR_WORKSPACE/governance/hangar-ai-constitution
2
Open Copilot CLI & paste this prompt

In your terminal, navigate to your workspace folder, then start Copilot CLI (gh copilot suggest or open a Copilot Chat session). Paste:

Run the setup installer from the Hangar AI Constitution to set up constitutional governance in my workspace. If you cannot locate the constitution or are not in the workspace root, stop and tell me before making any changes.

The agent runs the installer, copies the config file to your workspace, and confirms each step with you.

3
Restart your session

Start a new Copilot CLI session. The constitution loads automatically. You'll see a Session Ready report confirming active laws.

VS Code: enable via .github/copilot-instructions.md — the installer offers this automatically.
