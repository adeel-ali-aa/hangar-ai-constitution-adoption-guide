✈ Hangar AI — 15-Minute Quick Start

Your first AI response grounded in American Airlines engineering standards — in 15 minutes.

The Hangar AI Constitution is a set of laws, skills, and workflows that govern how AI assists engineering at American Airlines. This page gets you running in 15 minutes.

Already have git, GitHub access & Copilot?  Jump to Step 1 — or scroll down for the full guide.

Prerequisites

Before you begin, confirm you have the following:

  • git — installed and authenticated with GitHub (git --version)
  • GitHub access — access to AAInternal org repositories
  • GitHub Copilot licence — active Copilot subscription on your GitHub account
  • Copilot CLI — gh copilot installed (preferred — see tip below) or VS Code with Copilot Chat extension
💡 Recommended tool: The GitHub Copilot CLI provides the richest experience with the Hangar AI Constitution. If you haven't installed it yet, run: gh extension install github/gh-copilot

Step 1 — Clone the Hangar AI Constitution

Clone the constitution into a governance/ subfolder inside your workspace root. Replace <workspace-root> with the folder you open in your IDE (e.g. ~/Repos).

HTTPS (recommended)

Clone with HTTPS

git clone https://github.com/AAInternal/hangar-ai-constitution.git \
  <workspace-root>/governance/hangar-ai-constitution
SSH fallback

Clone with SSH

git clone git@github.com:AAInternal/hangar-ai-constitution.git \
  <workspace-root>/governance/hangar-ai-constitution

Step 2 — Run the Setup

Open a Copilot CLI session from your workspace root and paste this prompt. The agent runs the installer, copies AGENTS.md to your workspace root, and walks you through each step with your consent.

💻 VS Code user? Open Copilot Chat in your workspace, then paste the same prompt. Or jump to VS Code setup first.

✨ The magic — copy & paste this single prompt
What is the Hangar AI Constitution and what can you help me with today? Give me one thing I can try right now.
🔍 Want to preview first? Say: 
Show me what the setup will do before making any changes
The agent will run the installer in --dry-run mode — a full preview with zero files written.

Step 3 — Restart Your Session

After the setup completes, start a new Copilot CLI session from your workspace root. The constitution loads automatically on session start.

What to expect on first load

Session bootstrap

The agent will:

  1. Detect the constitution and ask if you want to pull the latest
  2. Display a 📰 What's New block if updates are pulled
  3. Post a Session Ready report showing sync status and active laws
  4. Ask which codebase you're working on today
✅ You're live. Every session from this workspace is now governed by the Hangar AI Constitution. Laws, skills, and workflows are active and binding.

Starter Prompts

Copy and run these in any Copilot CLI or Copilot Chat session to get started with the constitution in your day-to-day work.

🖥️ Set up the constitution on this machine
Clone https://github.com/AAInternal/hangar-ai-constitution into YOUR_WORKSPACE/governance/hangar-ai-constitution, then run setup/install.sh to set up constitutional governance in my workspace.
🏛️ Adopt the constitution in a repo
Adopt the Hangar AI Constitution in this repo. Run the constitutional adoption workflow — check state, resolve avatars, create hangar-ai-specs/, and set up AGENTS.md.
🚀 Start a new feature (greenfield)
I'm building [feature name]. Walk me through the Hangar greenfield workflow starting with Phase 1 Capture, tied to story [story ID].
🔧 Improve a legacy module
I need to improve [module or feature] in this codebase. Start the Hangar legacy rescue workflow and help me identify the right entry point.
⚖️ Run a phase gate
We've completed Phase [N] for [feature]. Run the phase gate — citation audit, 5-juror jury, synthesis, and gate check.
📋 Daily work tied to a story
I'm working on story [story ID]: [title] today. Use the Hangar AI Constitution to guide my implementation and keep me aligned with our engineering standards.

VS Code Users

Enable in VS Code Copilot Chat

The installer can also create .github/copilot-instructions.md in your workspace root. When prompted "Create .github/copilot-instructions.md for VS Code Copilot?" — answer y.

Then add this to your VS Code settings.json:

"github.copilot.chat.codeGeneration.instructions": [
  { "file": ".github/copilot-instructions.md" }
]
