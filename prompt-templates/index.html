Ready-to-paste prompts for every adoption phase · Copy → paste into Teams or Copilot chat

Phase 1 — Initial Adoption
Use when: first session with a new team, repo not yet adopted
Clones the constitution into the parent directory (if not already there), reads the adoption workflow, and runs the full adoption process — producing a PROPOSAL for your review before making any changes.
Clone the hangar-ai-constitution from github.com/AAInternal/hangar-ai-constitution.git to the parent directory of this project (i.e., ./../). If the folder already exists, pull latest from the server. Read hangar-ai-constitution/workflows/adoption-workflow and follow the guidance to fully adopt the AI constitution into this repo. Once complete, commit.
Scoping tip: If the full adoption is too large for one session, add to the prompt: "Scope this adoption to setup and AGENTS.md only — defer SonarQube provisioning and product avatar creation to a later session."
2
Phase 2 — First Governed Task
Use when: team has adopted, ready for their first constitutionally-governed feature or refactor
Reads the constitution (already in the parent directory) and governs a specific task — producing a PROPOSAL for the named ticket or story before any code changes are made.
The hangar-ai-constitution is already cloned at ./../hangar-ai-constitution/. Read it now, then strictly follow the constitution and create a new proposal for the following task: [DESCRIBE THE TASK HERE — e.g., "Refactor the MileageService class to reduce complexity and improve testability"] The proposal should include: problem statement, proposed changes, law citations, acceptance criteria, and an APPROVE / OBJECT gate. Do not make any changes until I approve the proposal.
Bounded context tip: If the codebase is large, specify the bounded context: "Scope this proposal to the com.aa.[package] package only." This prevents the agent from proposing changes across the entire codebase in one session.
3
Phase 3 — Follow-up Coaching Session
Use when: team has completed their first task, coaching on what comes next
Asks the agent to review the team's most recent constitutionally-governed PR, identify what went well and what could be improved, and propose the next highest-value constitutionally-governed task for the team to tackle.
The hangar-ai-constitution is already cloned at ./../hangar-ai-constitution/. Read it now. Review the most recent proposal in this repo's proposal archive and the corresponding PR. Assess: (1) were the law citations correct and complete? (2) did the implementation match the proposal? (3) did the SonarQube gate pass? Then propose the next highest-value constitutionally-governed task for this team based on the current state of the codebase. Explain why this task is the right next step and which laws it will exercise.
Coaching tip: Run this prompt WITH the team and use the agent's assessment to open a discussion. The agent's "what went well / what to improve" output is a direct conversation starter — don't pre-read it yourself before the session.
